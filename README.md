# Netcatty Codex Launcher

Windows x64 启动器，让 Netcatty 通过固定路径使用已安装的 ChatGPT 桌面版自带的 Codex。每次启动时，程序向 Windows 查询当前应用包位置，适配常规版本更新。

1. 从 [GitHub Releases](https://github.com/16bd/netcatty-codex-launcher/releases/latest) 下载 Netcatty-Codex.exe，并放在固定目录。
2. 在 Netcatty 的 **Agent → Codex** 中填入启动器的完整路径，然后点击 **检查**。

需要 Windows 版 ChatGPT 应用包。启动器依赖该应用包的包标识和内部可执行文件位置。
